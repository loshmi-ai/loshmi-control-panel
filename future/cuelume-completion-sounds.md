# Cuelume Completion Sounds

Use Cuelume sounds to denote completion of an action, not only the initial
click.

For example, the passkey sign-in button currently plays its sound when the user
clicks the button. The sound would make more sense after passkey sign-in
finishes successfully, when loading is complete and the app is about to redirect.

Future work should add an imperative completion-sound path for async actions
while keeping click sounds available for immediate button feedback.
